New Browser tab and CLI

Too big for a plugin window? Open it in a browser tab.

The winden-tokens command serves the same interface full-size on your machine and drives the Figma file you have open. Edits land in Figma right away, and selecting a component in Figma shows its card in the tab.

Keep the plugin window open in Figma. It is the only thing that can reach the Figma API.

  Now open the Winden Tokens plugin in Figma and leave that window open.
  Ctrl-C to stop.

  • Loopback only

    Listens on 127.0.0.1, so nothing on your network can reach it.

  • Origin-checked

    A web page you happen to have open cannot connect to it.

  • Stores nothing

    It forwards messages between the tab and Figma, and forgets them.

New MCP server

Let Claude manage your tokens. An MCP server for the Figma file you have open.

The same package installs an MCP server. Claude can list collections, read a variable and everything it references, create variables, groups and collections, and set values, all in the file you are working on.

Set it up in three steps

  1. 1

    Install the package

    npm install -g winden-tokens
  2. 2

    Add it to Claude Code

    claude mcp add winden-tokens -- winden-tokens-mcp
  3. 3

    Run it, then open the plugin in Figma

    winden-tokens

The tools Claude gets

  • list_collections

    Collections with their modes and counts.

  • list_variables

    Filter by collection, group, type or name.

  • get_variable

    A variable, its values per mode and everything it references.

  • create_collection

    An empty collection, ready for variables.

  • create_variable

    One variable. A slash in its name puts it in a group.

  • create_group

    A group of variables in one go.

  • set_variable_value

    A value or a {reference}, per mode.

  • rename_variable

    A new name. Aliases keep working, and a new path moves it to another group.

  • delete_variable

    Reports what it would affect, then deletes.

Renaming and deleting can’t be undone from Claude’s side. Figma’s own undo is the recovery.
